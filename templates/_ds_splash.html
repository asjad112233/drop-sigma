If a portal forgets to wire it, two safety nets fire: * window.load + 1.6s grace — page is fully loaded * absolute cap at 8s — never trap the user 4. A small "minimum visible time" prevents a sub-200ms flash on instant cache hits. The splash always shows for at least 350ms once the overlay is in the DOM. No required HTML on the host page — the partial owns the overlay node and removes it when done. {% endcomment %}
